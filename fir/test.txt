firebase --version


Version display aagala na:
npm install -g firebase-tools

firebase serve --only hosting

http://localhost:5000

Step 5: If college system asks you to log in
Local application run panna firebase login sometimes thevai illai for Firebase Hosting's local emulator/serve. If CLI asks for authentication, or you need to deploy changes, run:
firebase login


Un Firebase project-ku internet access irukkanum. Authentication and Firestore cloud-la irukkuradhunaala avai online-la connect aagum.
Step 6: If you change code in the lab
public/index.html-la changes pannina, local browser refresh pannu.
Changes-a online website-kum publish panna mattum:

firebase deploy --only hosting

If login kekkudhu-na:
firebase login


Correct Firebase project select aagirukka-nu check panna:
firebase use
